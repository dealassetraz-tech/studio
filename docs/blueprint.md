# **App Name**: Visually Enhanced Website Generator

## Core Features:

- UI Analysis: Analyze the provided UI screenshots, including layout, components, and color theme.
- UI Enhancement: Generate improved and enhanced UI/UX based on modern design standards. LLM reasoning will be employed as a tool in deciding when or if to incorporate elements from original screenshots.
- Responsive Design: Ensure the generated website is fully responsive and works on all OS and screen sizes.
- Code Generation: Generate complete, scalable, production-ready code (React + Tailwind CSS).
- Component Architecture: Implement a modular and scalable folder structure with reusable components.
- Dynamic Functionality Integration: Integrate dynamic functionalities as needed (forms, API calls, animations).
- Full Codebase Assembly: Assemble the entire project and provide the full working codebase incrementally as the screenshots are analyzed.

## Style Guidelines:

- Primary color: Deep Blue (#1E3A8A) for a professional and modern feel.
- Background color: Light gray (#F9FAFB) for a clean and unobtrusive backdrop.
- Accent color: Teal (#2DD4BF) for highlighting interactive elements and key information.
- Body font: 'Inter', sans-serif, for clean readability and modern aesthetic.
- Headline font: 'Space Grotesk', sans-serif, for bold, attention-grabbing headlines.
- Employ a grid-based layout for consistent spacing and alignment.
- Use a set of modern, minimalist icons to enhance user experience.
- Incorporate subtle transitions and animations to provide visual feedback and enhance interactivity.
